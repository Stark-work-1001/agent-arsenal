# 03 · 改动文档

> 记录本项目从零到功能完成的全部实现，按模块组织。

## 一、工程骨架

- 在项目根目录 `<项目根>` 新建 Electron 44 + React 19 + TypeScript + Vite 7 工程。
- 依赖安装走 npmmirror，Electron 二进制从本地缓存安装（`node node_modules/electron/install.js`）。
- 建立目录：`apps/desktop/src/{main,renderer}`、`tests`、`scripts`、`docs`、`arsenal`。
- 生成应用图标 `apps/desktop/build/icon.png`（脚本化生成，环形渐变 + 中心菱形）。

## 二、后端内核（`src/main`）

### core/

| 文件 | 内容 |
| --- | --- |
| `paths.js` | 数据目录解析（开发/打包两种形态）、来源根目录表、路径越界保护 |
| `util.js` | id/哈希/稳定序列化/版本比较/中文令牌化/文件遍历/原子写入/目录复制 |
| `yaml.js` | 手写 YAML 子集解析器（块映射、块序列、行内数组对象、多行 `|`/`>`、注释、frontmatter 提取） |
| `toml.js` | 手写 TOML 解析器（表、数组表、行内数组、嵌套点键） |
| `manifest.js` | Capability Manifest v1：类型归一、身份键、指纹、检索文本 |
| `text-index.js` | CJK 逐字切分、FTS 查询构建、短语近似评分、snippet |
| `events.js` | 事件总线 + 持久化事件流 + 订阅广播 |
| `logger.js` | 分级日志、控制台 + 按日文件 |

### db/

- `schema.js`：12 张业务表 + FTS5 虚表（unicode61）+ trigram 虚表 + 三个同步触发器。
- `db.js`：`Database` 封装（all/get/run/tx/backup/stats），WAL、busy_timeout、schema 版本。

### adapters/

- `skill.js`：SKILL.md 解析、资源清单、`hasFrontmatter`/`bodyChars` 事实记录。
- `mcp.js`：配置文件（JSON/YAML/TOML）三种键名兼容；工程目录识别（Node/Python/README）。
- `plugin.js`：DSH 插件（`dsh.bundle`/`dsh.client`）、Claude/Codex 插件、A2A Agent Card、OpenAPI。

### services/

| 文件 | 职责 |
| --- | --- |
| `context.js` | 组合根，装配全部服务 |
| `discovery.js` | 21 条内置发现规则 + 来源落库 |
| `scanner.js` | 按来源类型分派扫描、增量写入、消失清理、故障信号 |
| `registry.js` | 能力 upsert（版本更高才覆盖主体字段）、安装实例、检索文档维护、统计 |
| `search.js` | 三路融合检索、同义词扩展、解释性评分、浏览模式 |
| `dedupe.js` | 同名/相似检测、候选组落库、保留最新/合并/共存/忽略 |
| `faults.js` | 8 条诊断规则、自动修复（备份+原子写）、派单工单、补丁校验回传 |
| `lifecycle.js` | 启停/隔离/固定/快照/删除（回收站）/恢复/导出/校验 |
| `imports.js` | 导入预检与入库（复制到 arsenal/ 并登记来源） |
| `updates.js` | DSH Market 缓存导入、上游目录查询、并发更新检查（npm 可选） |
| `ecosystem.js` | 宿主目标枚举、MCP 配置预览/写入、备份与回滚 |
| `agents.js` | 进程识别（WMI→tasklist 降级）、心跳扫描、MCP 会话、状态归并 |
| `workflows.js` | 4 条内置工作流、步骤执行器、运行记录 |

### mcp/ 与 server/

- `mcp/server-core.js`：JSON-RPC 分发（initialize/ping/tools/resources/prompts）、10 个工具、会话与用量记录。
- `server/http.js`：REST（20+ 端点）+ MCP Streamable HTTP + `/health`，请求体与并发上限。
- `cli.js`：`serve` / `stdio` / `scan` / `search` / `heartbeat` 五个子命令。

### Electron

- `main.js`：单实例锁、窗口、服务启动、后台调度（1 分钟智能体、15 分钟扫描）、40+ IPC 通道、截图模式。
- `preload.cjs`：CJS 白名单桥（不是 ESM——这一点踩过坑，见经验文档）。

## 三、界面（`src/renderer`）

12 个视图：总览、能力库、检索实验室、智能体接入、来源与扫描、去重裁决、维修站、更新管理、工作流、生态同步、数据库、设置。

共享组件：`Badge/Stat/Tabs/Modal/Toast/Markdown/Empty/Spinner` + `useAsync`。
样式：单文件 `styles.css`（约 18 KB），深色青绿主题、语义化状态色、响应式栅格。
