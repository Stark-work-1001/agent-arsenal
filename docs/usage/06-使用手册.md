# 06 · 使用手册

## 启动

双击项目根下的 `release/启动-智能体核武库.cmd`（由构建脚本生成的快捷启动器）。首次启动会在后台扫描（约 20–30 秒），
顶部「扫描全部」按钮会显示扫描状态。数据保存在 `release/arsenal-data/`。

## 界面地图

左侧分三组：

- **能力中枢**：总览 / 能力库 / 检索实验室 / 智能体接入
- **治理**：来源与扫描 / 去重裁决 / 维修站 / 更新管理
- **运行**：工作流 / 生态同步 / 数据库 / 设置

### 总览

四个指标卡（能力总数、在线智能体、待处理故障、重复/可更新）+ 能力构成 + 来源分布 + 最近事件 + 工作流状态 + 高频能力。

「⚡ 执行全量巡检」会依次跑：扫描 → 诊断 → 去重 → 重建索引 → 汇总。

### 能力库

- 顶部：名称/摘要/作者过滤、类型分段、状态下拉、导入按钮
- 左侧列表：类型图标、名称、版本、健康徽章、作者、状态、宿主、更新时间
- 右侧详情：概览（作者/版本/宿主/标签/主页/许可证/调用次数）、正文（Markdown 渲染）、安装（路径/指纹/大小）、故障
- 操作：启用/停用、校验完整性、创建快照、固定、删除（移入回收站）、导出、打开安装位置

**导入能力**：点击「＋ 导入能力」→ 选择目录 → 先「预检」看清单与问题 → 再「确认入库」。
入库会复制到 `arsenal/<kind>/<slug>/`，原位置不变。

### 检索实验室

输入自然语言（中英均可），或点示例按钮。结果区可切换「结果 / JSON」。
每条结果下方显示匹配来源（名称/摘要/标签/子串/全文）。右侧面板展示同义词扩展词与打分构成。
「重建检索索引」在改了数据库后使用。

### 智能体接入

三通道识别的结果以卡片展示：运行中（进程识别）/ 心跳在线 / 未运行。
下方「MCP 接入配置」给出可直接复制的 JSON；「可写目标」列出能自动写入的宿主配置，
点「预览」看将写入什么，点「写入」执行（写入前自动备份）。

右侧「最近 MCP 会话」显示真实连入的客户端、请求次数、工具调用分布。

### 来源与扫描

按宿主分组列出全部来源：类型、根路径、上次扫描时间、状态、数量。
可以单来源扫描、停用、删除（内置来源不可删）。「＋ 添加来源」支持任意目录。

### 去重裁决

每组重复能力显示：相似度、实例数、判定原因、每个实例的版本/作者/路径/状态、推荐项（★）。
四个动作：**保留最新版本**（其余归档）、**合并**（实例并入目标并保留全部标签/宿主）、
**允许共存**、**忽略**。归档不删除磁盘文件。

### 维修站

- 顶部统计：未解决故障 / 可自动修复 / 已派单 / 维修记录
- 「执行诊断」跑全部规则
- 列表支持按状态与级别筛选
- 「自动修复」：仅对安全规则可用（补 frontmatter / 补 description），修复前自动备份
- 「派单」：选择智能体、写备注，生成结构化工单（自动复制到剪贴板）
- 点行打开详情：证据、维修历史（含修复前后哈希）

**工作方式**：中枢只诊断定位，修复由智能体执行；智能体修完通过 `arsenal.submit_patch` 回传完整文件内容，
中枢校验路径边界后备份落盘。

### 更新管理

两个标签：

- **已纳管能力**：检查全部更新（本地缓存优先，可选联网）、查看当前/上游版本、为更新前创建快照
- **上游市场**：3057 条 DSH Market 包目录，可搜索、标注已安装/未安装

### 工作流

四条内置流程（全量巡检 / 能力入库 / 更新巡检 / 智能体同步），点「执行」实时显示每一步状态与耗时。
右侧「执行过程」逐步展开；下方「运行历史」保留最近 50 次。

### 生态同步

列出可写入的目标（DSH 插件清单、DSH 能力配置、MiniMax、Claude、中枢自身）。
「预览」看片段，「写入」执行并自动备份；右侧「备份与回滚」可一键恢复。

### 数据库

实时指标（库大小、WAL、表行数、SQLite 版本）、全部表与行数占比、存储结构说明、可直接执行的 SQL 示例。

### 设置

运行信息（版本/数据目录/数据库/MCP 端点/服务状态）、自动化开关、回收站（可恢复）、
智能体接入指引与 10 个 MCP 工具清单。

## 让智能体接入

### 方式一：HTTP（推荐）

把下面配置加入宿主（或在「生态同步」里一键写入）：

```json
{
  "mcpServers": {
    "agent-arsenal": {
      "type": "streamableHttp",
      "url": "http://127.0.0.1:18297/mcp"
    }
  }
}
```

### 方式二：stdio

```json
{
  "mcpServers": {
    "agent-arsenal": {
      "command": "node",
      "args": ["<项目根>/apps/desktop/src/main/cli.js", "stdio"]
    }
  }
}
```

### 方式三：心跳（无 MCP 能力的宿主）

```bash
node apps/desktop/src/main/cli.js heartbeat --host dsh --name "DeepSeek Harness"
```

写入 `arsenal-data/run/heartbeats/dsh.json`，中枢每分钟扫描一次。

## 智能体侧的典型调用序列

```text
1. arsenal.search { "query": "把论文转成网页", "limit": 5 }
   → 返回候选能力与 id
2. arsenal.read_skill { "id": "cap_xxx" }
   → 返回 SKILL.md 全文，按说明执行
3. arsenal.report_usage { "capabilityId": "cap_xxx", "action": "use" }
   → 记录一次使用（影响排序）
```

维修场景：

```text
1. arsenal.list_faults { "status": "open" }
2. 读取 evidence.path，自行修复文件
3. arsenal.submit_patch { "faultId": "...", "file": "...", "content": "完整文件内容", "message": "说明" }
```

## 常见问题

**Q：扫描很慢？**
首次全量约 20–30 秒（300+ 能力）。之后每次扫描只更新变化的文件，但仍是全量遍历；后续可做增量优化。

**Q：为什么「能力库」里有未声明的作者？**
很多技能没有在 frontmatter 里写 author，也没有仓库信息。核武库**不猜**——显示「未声明」而不是拿目录名冒充。

**Q：删除了能力，宿主那边还能用吗？**
删除只影响中枢纳管的副本与原路径文件（移入回收站）。宿主自己的配置若指向该文件，需要宿主侧重启或同步。

**Q：两个智能体同时访问 18297 端口冲突？**
单实例锁保证只有一个中枢进程；重复启动会把已有窗口提到前台。

**Q：数据库能直接看吗？**
可以，标准 SQLite 文件：`release/arsenal-data/arsenal.db`。注意应用运行时有 WAL 文件，建议用只读方式打开。
